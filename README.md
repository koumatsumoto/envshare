# envshare

チームで共有する dotenv 設定だけを暗号化して Git に置き、各自の `.env` に差分を追記する CLI。外部サービスや実行時の npm 依存はありません。最新の Windows・macOS・Linux と、Node.js 24・26 各系列の最新パッチをサポートします。

## インストール

公開版は `npm install --global @kou-matsumoto/envshare` でインストールします。TypeScript や追加のライブラリは不要です。

## 使い方

1. 各プロジェクトの `.gitignore` に `.env`、配布元の `.env.share.local`、`.envshare-tmp-*/` を入れ、平文が既に追跡されていないことを確認します。共有鍵は暗号文とは別の経路で渡し、受け取った人は Git 管理外の `.env` に `ENVSHARE_KEY` を設定します。鍵はランダムな32バイトの標準 Base64（パディング付き）です。
2. 配布側は、共有したいキーだけを `.env.share.local` に書き、`envshare encrypt .env.share.local` を実行します。Git に追加するのは `envshare.enc` だけです。出力名を変える場合は `--out <path>` を指定できます。既存ファイルは envshare の暗号ファイルの場合だけ置換します。
3. 受取側は `envshare.enc` があるプロジェクトのルートで `envshare sync` を実行します。明示的に用意した環境変数から初回登録するなら `envshare sync --bootstrap`。環境変数 `ENVSHARE_KEY` を使い、同期成功時だけローカル `.env` に保存します。両方に異なる鍵があれば失敗します。

CLI をまだ PATH に登録していなくても、コマンド中の `envshare` を `node <checkout>/src/cli.ts` に置き換えれば、対応する Node.js だけで直接実行できます。パスに空白があれば、スクリプトへのパスを引用符で囲んでください。

## 同期のルール

- 同名キーは末尾が有効です。実効値が同じなら何も書きません（引用符の違いは無視）。新しいキーや値だけ末尾に追記し、古い値、コメント、ローカルの設定は削除しません。空文字列は未定義と区別します。
- Node.js の [dotenv 文法](https://nodejs.org/api/environment_variables.html#dotenv)に従う UTF-8 を受け付けます。曖昧な記法や BOM 付きファイル、大小文字だけが異なる設定名の併存は拒否します。変数展開やシェル実行はしません。
- 鍵がない場合は入力待ちせずに失敗します。認証・構文確認が済むまで書き込みません。通常ファイルだけを扱い、入力・出力のファイル自体がシンボリックリンクの場合は拒否します。
- Git 作業ツリーでは、暗号化前に鍵を含む `.env` と配布元、同期で書き込む前に `.env` と一時ファイルが未追跡かつ無視対象であることを確認します。確認できなければ処理を中止します。信頼できるプロジェクトと作業ツリー外の Git を使い、暗号ファイルにはテキスト変換を設定しないでください。
- 変更時は同じディレクトリ内で原子的にファイルを置き換えるため、書き込み可能な作業場所が必要です。同じ `.env` を同期中に別プロセスで編集しないでください。macOS・Linux では手作業で用意する平文ファイルも `0600` を推奨し、CLI が変更する `.env` は `0600` にします。Windows では置換前の個別ファイル ACL を引き継がないため、自分のアカウントに限定した ACL のフォルダで使ってください。

共有範囲・環境ごとに鍵を分けます。共有鍵を持つ人は同じ暗号文を読めて、新しい暗号文も発行できます。過去の暗号文や既に取得された値は、いまの鍵を変えるだけでは失効しません。ローカルに残る古い設定値は必要に応じて手で整理してください。

## 開発

`npm ci` で開発用の TypeScript 7 コンパイラ（実行環境に合うネイティブバイナリ）と Node.js の型定義をインストールします。`npm test` は厳格な型検査・ビルドの後、生成した CLI の発行と同期をダミーの鍵・設定で検証します。

`npm pack` でもビルドを実行します。配布する実装は `dist/` の JavaScript のみで、利用者側ではビルドしません。`npm run test:package` は実際の配布アーカイブを空のディレクトリにオフラインでインストールし、暗号化・同期まで確認します。
